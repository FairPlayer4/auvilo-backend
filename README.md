# avlreminder-backend

Experimentelles Backend für avlreminder auf Google Cloud: Synchronisation zwischen
Anwendern mit Ende-zu-Ende-Verschlüsselung, EU-Datenhaltung und optionaler Cloud-KI.
Lernprojekt, vorerst nicht mit der App verbunden.
